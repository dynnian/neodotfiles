# Suckless Terminal (st) Patch Note - 2026-07-07

## Sixel Graphics Support Integration

Implemented native DEC Sixel graphics support inside `st` utilizing the `sixel` decoding engine and `imlib2` image library. This enables command-line applications like `yazi`, `lsix`, and `neovim` to render graphics directly in the terminal cells.

### Changes Summary
1. **Build System & Dependencies (`config.mk`, `Makefile`)**:
   - Integrated `-lImlib2` to resolve Imlib2 dependencies for image scaling and graphics format conversions.
   - Added compiler targets for `sixel.o` and `sixel_hls.o`.
2. **Terminal Data Parsing & Flow (`st.c`, `st.h`)**:
   - Added Sixel-specific modes (`MODE_SIXEL`, `MODE_SIXEL_CUR_RT`, `MODE_SIXEL_SDM`, `MODE_SIXEL_PRIVATE_PALETTE`) to the terminal mode flags.
   - Updated `twrite` to intercept Sixel DCS byte sequences and route them to `sixel_parser_parse`.
   - Updated the DCS escape sequence handler in `tputc` to initialize the Sixel parser upon receiving `'q'`.
   - Handled Sixel image scrolling, alternate screen swapping, and screen/scrollback clearing operations (`case J`).
3. **Decoupled Types & X11 Drawing (`x.c`, `win.h`)**:
   - Decoupled `XWindow` struct from Xft/XRender types to prevent macro/type naming collisions (specifically `Glyph`) in the core terminal parsing unit (`st.c`).
   - Extended `xfinishdraw` to scale Sixel graphics based on cell size (`win.cw`, `win.ch`) using `Imlib2` and draw them on screen via `XCopyArea`.
   - Implemented automatic cleanup of Sixel pixmaps upon font zoom level changes to trigger re-scaling.
   - Added custom helper queries `xgetcw`, `xgetch`, and `xgetbgcolor`.
    - Updated `vtiden` to `"\033[?62;4c"` to announce VT200 identity with Sixel support.
    - Defined `sixelbyteorder` for local RGB ordering.

## Silenced Unrecognized SGR / Private Mode Warnings
- **SGR 58 & 59 (Underline Colors)**: Added cases in `tsetattr()` to silently ignore underline color set/reset commands instead of printing warnings to stderr.
- **Private Mode 2026 (Synchronized Updates)**: Added private mode case in `csihandle()` to silently ignore screen synchronized updates commands, preventing log pollution during heavy redraws by modern CLI applications.

## Terminal Query & Sixel Compatibility Enhancements
- **Sixel DCS Headers with Macros**: Fixed parser state machine detection in `tputc` to inspect both `csiescseq.mode[0]` and `csiescseq.mode[1]` for the final Sixel character `'q'`. This properly parses macro-prefixed headers like `ESC P 9;1$q` sent by `yazi` without breaking rendering or spilling into STR errors.
- **Secondary Device Attributes (CSI > q)**: Implemented standard xterm secondary device attributes/version query handler under `case 'q'` in `csihandle()`, returning `ESC P > | st 0.8.5 ESC \` to satisfy application feature checks.
- **DECRQSS (DCS $ q)**: Implemented standard VT/xterm DCS Request Status String query response in `strhandle()`, correctly replying with "unsupported" (`ESC P 0 $ r <request> ESC \`) to prevent unresolved string dumps. Changed case `'P'` in `strhandle()` to `return` instead of `break` to prevent both Sixel sequence finalizations and empty DECRQSS queries from falling through and printing default unknown string warnings.

## Viewport Selection Scroll Fix
- **Selection Preservation on Viewport Scroll**: Implemented a new selection scroll helper `selscrollview()` called by `kscrollup()` and `kscrolldown()`. This updates selection bounds during scrollback navigation without validating viewport-clipping bounds (which otherwise causes standard `st` to reset/clear selections when the selection origin is scrolled off-screen). Selection coordinates are clamped to active memory bounds `[-term.scr, term.row - 1]` to ensure memory safety.
