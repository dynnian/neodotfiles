# DWM Patch Notes — 2026-07-06

This patch introduces configurable systray geometry controls, alignment bug fixes for padded status bars, memory safety audits, and code robustness updates.

**Release Date:** 2026-07-06  
**Target:** Custom dwm build (v6.4)  
**Author:** Pair programmed with Antigravity AI Assistant  

---

## 1. Systray Geometry Customization

* **Configurable Icon Sizes & Spacing:** 
  Introduced parameters in `config.h` to decouple the size of the systray icons from the font-defined bar height (`bh`):
  - `systrayiconsize` (default: `16`): Set a fixed size for icons. Set to `0` to dynamically fit the bar.
  - `systrayvpad` (default: `4`): Vertical padding around icons.
  - `systrayhpad` (default: `8`): Horizontal padding/spacing between icons and at the tray borders.
* **Systray Status Separator:**
  Added support for a text-based separator (e.g., `|`) between the status bar text and the systray, configured via `systraysep` in `config.h`. The separator width is calculated dynamically without adding extra padding, resulting in a clean boundary.
* **Vertical Alignment:**
  Systray icons are now perfectly centered vertically using `(bh - i->h) / 2`.

---

## 2. Status Bar Alignment & Padding Fixes

* **Coordinate Realignment:**
  Previously, status text and the systray background were positioned using the monitor width (`m->ww`), while the window title area used the padded bar window width. In setups with non-zero side padding (`sp`), this caused a `2 * sp` unpainted gap on the right and clipped the status text.
  - Aligned all coordinates in `drawbar()` and click check ranges in `buttonpress()` relative to the padded bar width `barw = m->ww - 2 * sp`.
  - Removed duplicate `2 * sp` padding calculations.
  - Status text now ends flush with the separator, and window titles align perfectly to the start of the status text without overlapping.

---

## 3. Critical Bug & Memory Safety Fixes

* **X Server Pixmap Resource Leak:**
  Fixed a duplicate block in `drw_create()` where `XCreatePixmap` was called twice, overwriting the first handle and permanently leaking X server pixmap resources.
* **Uninitialized Variable in `geticonprop`:**
  Initialized loop step size `sz = 0` to prevent undefined behavior and compiler warnings when evaluating `i += sz` on empty property queries.
* **Strict Aliasing Violation:**
  Replaced a type-punned cast (`(uint32_t *) bstp`) with a standard-compliant dynamic allocation and copy mechanism using `ecalloc`. This avoids silent data corruption during optimization.
* **Pertag Memory Leak:**
  Added `free(mon->pertag)` inside `cleanupmon()` to clean up per-monitor layout statistics upon monitor layout shifts or shutdown.

---

## 4. Minor Fixes & Quality Enhancements

* **Centered Title & Icon Overlaps:**
  Redesigned centering logic in `drawbar()` to center the window icon and title text together as a single visual group. Long titles now scale and clip gracefully rather than overwriting the window icon.
* **Dynamic Monocle Lookup:**
  Replaced hardcoded layout index `layouts[2]` with a dynamic search matching `arrange == monocle`. Fullscreen layouts will no longer break if layout ordering in `config.h` is rearranged.
* **Layout Sentinel Safety:**
  Added checks in `setlayout` to prevent dereferencing or copying from `NULL` when cycling close to sentinel structures.
* **Remote X11 Endianness Correction:**
  Adjusted scaling visual generation inside `drw_picture_create_resized` to detect host-endianness at runtime and feed it to the X11 server, preventing swapped color channels (Red/Blue swaps) in remote sessions.
* **Visual Info Safeguard:**
  Added a null check to `XFree(infos)` inside visual initialization to prevent segmentation faults on visual query failures.
